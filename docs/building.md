# Сборка

## Что нужно

| Что | Зачем | Где взять |
|---|---|---|
| PSn00bSDK | компилятор MIPS, библиотеки, `mkpsxiso` | [github.com/Lameguy64/PSn00bSDK](https://github.com/Lameguy64/PSn00bSDK) |
| CMake 3.21+ и Ninja | сборка кода и образа | пакеты дистрибутива |
| Python 3 и Pillow | сборка данных | `pip install pillow` |
| DejaVu Sans | растеризация шрифта | пакет `fonts-dejavu-core` |
| psxavenc | только для видео и озвучки | [github.com/WonderfulToolchain/psxavenc](https://github.com/WonderfulToolchain/psxavenc) |
| ffmpeg | подготовка видео | пакеты дистрибутива |

Проект проверялся с GCC 12.3.0 и `mkpsxiso` 2.03 из поставки PSn00bSDK.

Свой шрифт вместо DejaVu задаётся переменной окружения:

```bash
export VN_FONT=/путь/к/шрифту.ttf
```

## Сборка в три шага

```bash
export PSN00BSDK_LIBS=/путь/к/sdk/lib/libpsn00b

# 1. данные: картинки, шрифт, музыка, сценарий, список файлов образа
python3 tools/build_data.py

# 2. настройка сборки (один раз)
cmake -S . -B build -G Ninja \
      -DCMAKE_TOOLCHAIN_FILE=$PSN00BSDK_LIBS/cmake/sdk.cmake

# 3. код и образ диска
cmake --build build
```

Результат — `build/vn.bin` и `build/vn.cue`.

**Порядок важен.** `build_data.py` создаёт файлы в `data/` и переписывает
список файлов в `iso.xml`. Если он упал, образ соберётся по старому
`iso.xml` и `mkpsxiso` пожалуется на отсутствующий файл — смотрите вывод
первого шага, а не последнего.

**Новый исходник `.c`** нужно добавить в список в `CMakeLists.txt` и
пересоздать каталог сборки: Ninja запоминает список файлов.

```bash
rm -rf build
cmake -S . -B build -G Ninja -DCMAKE_TOOLCHAIN_FILE=$PSN00BSDK_LIBS/cmake/sdk.cmake
```

То же при смене `CMAKE_BUILD_TYPE` или ключей `-D...`.

## Что делает сборка данных

`tools/build_data.py` за один проход:

1. растеризует шрифт в `data/SYS/FONT.TIM` и таблицу ширин `FONT.WID`;
2. переводит картинки из `art/` в TIM и складывает в общий файл `data/ART.PAK`;
3. конвертирует MIDI из `music.txt` в `data/BGM/M000.SEQ` и далее;
4. собирает банк инструментов `data/BGM/BANK.VAB` по `instruments.txt`;
5. собирает озвучку `data/VOICE.XAS` по `voice.txt`, если он есть;
6. готовит заголовок сохранения с иконкой `data/SYS/SAVEHDR.BIN`;
7. компилирует сценарий в главы `data/SCR/CH00.VNS` и далее, таблицы глав
   и галереи;
8. проверяет, что каждый файл помещается в свой буфер в памяти приставки;
9. переписывает список файлов в `iso.xml`.

Ошибки вида «неизвестный ресурс», «неизвестный звук», «глава без фона»,
«файл не влезет в буфер» ловятся здесь, на компьютере, а не чёрным экраном
на приставке.

Проверить собранные главы отдельно:

```bash
python3 tools/verify_chunks.py
```

## Релизная сборка

```bash
python3 tools/build_data.py --release
rm -rf build
cmake -S . -B build -G Ninja -DVN_RELEASE=ON \
      -DCMAKE_TOOLCHAIN_FILE=$PSN00BSDK_LIBS/cmake/sdk.cmake
cmake --build build
```

В релизе нет печати в терминал (на приставке она уходит в последовательный
порт и стоит около 4 мс на строку), отладочного оверлея по кнопке Select и
таблицы имён `NAMES.DBG` в образе. Мигание кодом при фатальной ошибке
остаётся: без него игрок увидит просто чёрный экран.

## Файл лицензии Sony

Приставка без модчипа при загрузке проверяет лицензионный блок в начале
диска. Его содержимое — файл `licensea.dat` (для американского региона;
`licensee.dat` для европейского, `licensej.dat` для японского). Файл
принадлежит Sony и **в репозиторий не входит**.

- Если положить его в корень проекта, сборка данных включит его в образ.
- Если его нет, образ собирается без лицензионного блока, а сборка
  предупреждает об этом. Такой образ работает в эмуляторах и на приставках
  с модчипом или ODE (PicoStation и подобными).

## Запуск

**Эмуляторы.** DuckStation и PCSX-Redux открывают `vn.cue` напрямую. Для
сохранений включите в эмуляторе карту памяти в первом слоте.

**Записанный диск.** `vn.bin` и `vn.cue` записываются на CD-R как образ
режима Mode 2/2352 любой программой, понимающей `.cue`.

**ODE** (PicoStation и подобные) принимают `.bin`/`.cue` как есть.

Проверяйте на живой приставке всё, что касается привода и карты памяти:
эмуляторы в этом снисходительнее железа, см. [platforms.md](platforms.md).

## Отладка

- **Select** во время игры включает отладочный оверлей: текущий фон,
  глава, позиция в сценарии, состояние, итоги последнего ролика.
- Печать `LOG(...)` уходит в терминал эмулятора или в последовательный
  порт приставки.
- `tools/unpak.py data/ART.PAK` показывает содержимое общего файла картинок.
- `tools/probe_str.py` разбирает файл видео по секторам.
- `tools/verify_seq.py`, `tools/verify_vab.py` проверяют музыку и банк.
