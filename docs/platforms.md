# Платформы и отладка на железе

## Совместимость

| Платформа | Состояние | Примечание |
|---|---|---|
| PlayStation, записанный CD-R | работает | основная цель |
| PlayStation + PicoStation | работает | после явного подъёма привода, см. ниже |
| Встроенный эмулятор PS3 | работает | то же |
| DuckStation | работает | карта памяти — через файловые вызовы BIOS |
| PCSX-Redux | работает | |
| PS2 через POPS | не поддерживается | зависает на первом чтении данных |

Эмуляторы на ПК снисходительнее железа во всём, что касается привода и
карты памяти. Всё, что трогает эти устройства, проверяйте на приставке.

## Что выяснилось по дороге

Эти различия стоили многих часов, поэтому записаны здесь — на случай, если
вы будете менять соответствующий код.

**Подъём привода.** После `CdInit()` на PicoStation и в эмуляторе PS3
разборщик файловой системы отвечал «это не ISO9660», хотя загрузчик BIOS с
того же диска только что прочитал `SYSTEM.CNF`. Привод оставался в
состоянии, которого библиотека не ожидала. Лечится явной
последовательностью: пустая команда, чтение оглавления, режим обычных
секторов по 2048 байт (снятый бит `CdlModeSize`), и только потом поиск
файлов. Это в `cd_init()`.

**Опрос чтения.** Ожидание конца чтения опросом нужно, чтобы во время
загрузки играла музыка. Опрос должен идти **раз в кадр**: плотный цикл не
оставлял времени обработчику прерывания, и чтение не завершалось никогда.

**Режим привода у озвучки.** Озвучка выставляет свой режим перед каждой
репликой. Попытка запомнить «режим уже наш» сломалась: режим меняют четыре
разных места, и стоило забыть одно, как привод оставался на двойной
скорости, а аудиосекторы уходили в буфер данных вместо звука.

**Карта памяти.** Низкоуровневые вызовы `_card_*` асинхронные и требуют
отдельно открытых событий BIOS; в DuckStation запись через них «проходила»,
но данные не появлялись. Основной путь — файловые вызовы BIOS (`bu00:`),
и после записи файл перечитывается для проверки.

**Буферы чтения.** `CdRead` пишет целыми секторами по 2048 байт. Буфер «по
размеру файла» меньше сектора — отказ чтения. Сборка данных проверяет и
это, и обратное.

**POPS.** На PS2 через POPS запуск доходит до первого чтения данных с
диска и останавливается навсегда, при любом способе ожидания. Платформа
рассчитана на коммерческие диски, и поддержка исключена.

## Коды ошибок

Если запуск сорвался, экран мигает красным сериями. Число вспышек в серии
— код:

| Вспышек | Что случилось |
|---|---|
| 1 | нет `DATA/SYS/FONT.TIM` |
| 2 | нет `DATA/SYS/FONT.WID` |
| 3 | нет первой главы `DATA/SCR/CH00.VNS` |
| 4 | `FONT.TIM` найден, но не прочитался |
| 5 | `FONT.WID` найден, но не прочитался |
| 6 | `CH00.VNS` найден, но не прочитался |
| 7 | не прочитался даже `SYSTEM.CNF` в корне диска |
| 10 | привод поднят, но `SYSTEM.CNF` не находится |
| 11 | сбой позиционирования привода |
| 12 | не читается дескриптор тома |
| 13 | диск не распознан как ISO9660 |
| 14 | открыта крышка |

«Не найден» и «не прочитался» — разные диагнозы: первое — ошибка сборки
образа, второе — привод или качество болванки.

## Сообщения экрана сохранений

| Сообщение | Причина |
|---|---|
| `saved` / `loaded` | всё в порядке |
| `here you cannot save` | сохраняться можно только на реплике, ждущей нажатия |
| `no icon file` | не загрузился `SAVEHDR.BIN` |
| `no card in slot 1` | карта не отвечает |
| `card status bad` | карта отвечает, но сообщает об ошибке |
| `frame write refused`, `directory write failed` | не прошла запись |
| `write did not land` | запись «прошла», но при перечитывании данных нет |
| `record too big` | запись сохранения не помещается в слот |
| `slot is empty` | в выбранном слоте ничего нет |
| `bad format`, `old version` | запись повреждена или от старой версии формата |
| `other build` | сценарий пересобран с другими главами |
| `no such chapter` | глава переименована или удалена |
| `gallery is empty` | ни одной сцены ещё не открыто |

## Отладочный оверлей

Кнопка **Select** (не в релизной сборке) показывает поверх игры: имя
текущего фона, номер главы и позицию в байткоде, состояние интерпретатора,
играет ли музыка, итоги последнего ролика (кадров показано, потеряно,
ошибок декодирования).

## Управление

| Кнопка | Действие |
|---|---|
| крестик, кружок, Start | дальше / выбрать |
| вверх, вниз | выбор варианта |
| L1 | сохранить |
| R1 | загрузить |
| треугольник | закрыть экран сохранений или галереи |
| влево, вправо | листать галерею |
| Select | отладочный оверлей |
