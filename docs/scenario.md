# Язык сценария

Сценарий лежит в `script/main.vns` — это обычный текстовый файл в UTF-8.
Компилятор `tools/build_data.py` превращает его в байткод и режет на главы,
которые движок подгружает с диска по мере надобности.

Все примеры ниже собираются компилятором как есть. Имена картинок взяты из
демо-игры в репозитории (фоны `uni`, `meadow`, `club`, персонаж
`sylvie_green`), так что их можно копировать прямо в `script/main.vns`.

Всё, что не распознано как команда, считается **репликой** и выводится в
текстовое окно.

---

## Как устроена строка

Одна строка — одна команда. Регистр команды не важен, `BG` и `bg`
равнозначны. Пустые строки и всё после `#` игнорируются.

```
# комментарий на всю строку
bg uni           # и в конце команды тоже
```

Комментарий в конце строки отрезается **только у команд**. В реплике
решётка остаётся обычным символом, поэтому строка `Стоимость # 5 йен.`
выведется целиком.

**Метки** начинаются с собачки и служат целью для переходов:

```
@start
@bad_ending
```

---

## Быстрый пример

```
@start
chapter "Лекция"

fade out 1s
bg uni
fade in 1s

wait 1s

char 0 sylvie_green/smile 84 7
name Сильви
Привет! Как тебе урок?

char 0 hide
fade out 1s
bg meadow
fade in 1s

name
Вскоре мы дошли до лугов на окраине.
end
```

## Единицы времени

Почти везде, где нужна длительность, число означает **кадры развёртки** —
их 60 в секунде. Суффикс `s` переводит в секунды, и так обычно понятнее:

```
wait 30      # полсекунды
wait 0.5s    # то же самое
wait 5s      # пять секунд
```

Это стоит запомнить: `wait 5` — это **пять кадров**, восемь сотых секунды,
а вовсе не пять секунд.

## Текст

### Реплика

Любая нераспознанная строка выводится в окно с эффектом печатной машинки.
Переносы по словам считает компилятор, вручную ломать строки не нужно.

```
Когда мы вышли из университета, я тут же заметил её.
Конечно, но что такое "визуальная новелла"?
```

Кавычки, запятые и обычная пунктуация работают. А вот **длинного тире,
ёлочек и многоточия в шрифте нет** — они молча превратятся в пробелы.
Пишите обычный дефис и три точки подряд. Импорт из Ren'Py
(`tools/import_renpy.py`) заменяет их сам.

**Длинная реплика делится на страницы.** В окно помещается три строки;
если реплика длиннее, компилятор сам разрежет её по границе строк на
несколько страниц, между которыми игрок нажимает кнопку. Имя говорящего
при этом сохраняется. При сборке это видно сообщением:

```
реплика разбита на 2 страницы: Она повернулась ко мне и улыбнулась...
```

### `name` — имя говорящего

```
name Сильви  # показать плашку с именем
name         # убрать плашку
```

Плашка держится, пока её не сменят или не уберут. Для авторской речи
ставьте `name` без аргумента.

### `clear` — очистить окно

```
clear
```

Убирает текущую реплику, оставляя окно пустым.

### `box` — показать или спрятать окно

```
box off      # спрятать текстовое окно
box on       # показать снова
```

Пригодится, когда нужно дать зрителю посмотреть на картинку без помех.

## Изображение

### `bg` — фон

```
bg uni
```

Имя — это имя файла из `art/bg/` без расширения. Фон занимает весь экран
320×240; картинку другого размера конвейер впишет сам.

### `char` — персонаж

```
char 0 sylvie_green/normal 84 7   # показать в слоте 0
char 0 hide                        # убрать из слота 0
```

Аргументы: номер слота, имя, затем координаты по горизонтали и вертикали.
Имя складывается из папки и файла: `art/char/sylvie_green/normal.png` даёт
`sylvie_green/normal`.

**Слотов четыре**, от 0 до 3. Смена выражения — это просто новая команда в
тот же слот, со старыми координатами:

```
char 0 sylvie_green/normal 84 7
char 0 sylvie_green/smile 84 7
```

#### Про координаты

Точка отсчёта — левый верхний угол **спрайта**. Спрайт бывает до 256×256
пикселей; чтобы поставить фигуру ногами на нижний край экрана и по центру
нужной точки, считайте так:

```
x = центр - ширина / 2
y = 240 - высота
```

Ширину и высоту печатает сборка, например
`sylvie_green/normal char 152x233`. Отсюда `x = 160 - 76 = 84`,
`y = 240 - 233 = 7` — так Сильви стоит в демо.

Учтите, что **текстовое окно полупрозрачное**: фигура видна сквозь него,
и нижняя часть спрайта не пропадает, а просматривается. Отрицательный `y`
поднимает фигуру, но срезает верх.

Если в исходной картинке вокруг фигуры много пустого места, точка
отсчёта сдвигается вместе с ним. Тогда либо обрежьте поля в редакторе,
либо подбирайте `x` по видимой фигуре, а не по рамке.

#### Раскладки по горизонтали

Экран — 320 пикселей. Для спрайта шириной 152 (как `sylvie_green`):

Один, по центру:

```
char 0 sylvie_green/normal 84 7
```

Двое, по третям экрана:

```
char 0 sylvie_green/normal  12 7
char 1 sylvie_blue/normal  178 7
```

Трое — фигуры частично перекрываются, что для новеллы нормально:
собеседники заслоняют друг друга.

```
char 0 sylvie_green/normal  -12 7
char 1 sylvie_blue/normal   105 7
char 2 sylvie_green/smile   180 7
```

Четверо — только внахлёст, крайние слегка уходят за край. Годится, когда
двое в глубине, а двое ближе:

```
char 0 sylvie_green/normal -36 7
char 1 sylvie_blue/normal   65 7
char 2 sylvie_green/smile  124 7
char 3 sylvie_blue/smile   225 7
```

Порядок отрисовки — по номеру слота: слот 0 оказывается **поверх**
остальных. Ставьте в него того, кто ближе к зрителю.

### `scene` — анимированный фон

```
scene rain      # смена кадра каждые 8 кадров развёртки
scene rain 12   # задать свою задержку
```

Кадры берутся из папки `art/scene/rain/` по алфавиту, **не больше
четырёх**. Годится для дождя, мерцания, бегущих облаков.

### `fade` — затемнение

```
fade out 1s         # погасить экран за секунду
fade in 30          # проявить за 30 кадров
fade out 1s music   # погасить вместе с громкостью музыки
```

Число — это **длительность**, а не скорость. Слово `music` ведёт громкость
синхронно с картинкой: звук уходит в тишину и возвращается вместе с
изображением.

**Важный порядок.** Меняйте фон, пока экран чёрный, иначе зритель увидит
подмену:

```
fade out 1s
bg meadow        # меняем, пока экран чёрный
fade in 1s
```

### Экранные эффекты

Ни один из них не занимает видеопамять, поэтому пользоваться ими можно
свободно.

#### `shake` — тряска

```
shake 0.5s      # трясти полсекунды
shake 0.5s 6    # сильнее, по умолчанию 3 пикселя
```

Дрожит **весь экран разом** — фон, персонажи и текст, — потому что
смещается не картинка, а показываемая область видеопамяти. Тот самый
эффект, что в аниме при ударах.

Тряска не блокирует сценарий: реплики продолжают идти, пока экран дрожит.

#### `flash` — вспышка

```
flash 10        # белая, 10 кадров
flash 10 red    # красная, есть ещё blue
```

Гаснет сама: в начале плотная, к концу прозрачная. Удобно для ударов,
молнии, резкого воспоминания.

#### `tint` — тонирование

```
tint 60 40 20   # тёплый закат
tint 20 20 60   # холодная ночь
tint off        # убрать
```

Держится, пока не выключат. Три числа — доли красного, зелёного и синего
от 0 до 255. Рисуется под текстом, поэтому реплику не заливает.

#### `slide` — сдвиг фона

```
slide left 0.5s
bg meadow
fade in 0.5s
```

Фон уезжает за край, экран пустеет. Направления: `left`, `right`, `up`,
`down`. Заменяет `fade out` там, где нужен более резкий переход.

Въезда нового фона пока нет — для него понадобился бы второй слот фона в
видеопамяти, а свободного места на него не хватает.

## Звук

### `bgm` — музыка

```
bgm play theme        # играть по кругу
bgm play theme once   # проиграть один раз
bgm stop              # остановить
bgm fadeout 120       # увести за 120 кадров
bgm fadein 120        # вернуть
bgm volume 90         # громкость 0..127
```

Имя трека берётся из `music.txt`. Музыка играет через звуковой процессор и
не занимает привод, поэтому продолжает звучать во время загрузок.

### `voice` — реплика голосом

```
voice sylvie_hi
```

Имя из `voice.txt` (строка вида `sylvie_hi voice/sylvie_hi.wav`). В демо
озвучки нет; как её подготовить — в `docs/assets.md`. Реплика играет **фоном** — сценарий её не ждёт, иначе
текст застыл бы до конца звука.

Важное следствие: пока идёт голос, привод занят потоком. Любая загрузка
картинки оборвёт реплику, поэтому не ставьте `bg` или `char` сразу после
`voice`, если хотите дослушать.

### `se` — звуковой эффект

```
se click
se hit
```

Имя берётся из `instruments.txt`, строкой вида:

```
sfx  click  hihat      # звук «click» использует сэмпл hihat
sfx  hit    snare
```

Первое имя — то, чем пользуется сценарий, второе — сэмпл: либо файл
`instruments/<имя>.wav`, либо один из встроенных синтезированных звуков
(`kick`, `snare`, `hihat`, `crash`, `clap`, `tom`, `shaker` и другие).

Эффекты играют на **отдельных голосах**, свободных от музыки, поэтому ноту
никогда не обрывают. Голоса перебираются по кругу: несколько эффектов
подряд накладываются, а не глушат друг друга.

Неизвестное имя ловится при сборке:

```
неизвестный звук 'door' — нужна строка «sfx door <сэмпл>» в instruments.txt
```

## Видео

```
str intro           # проиграть ролик
str intro fps 15    # задать частоту кадров (по умолчанию 15)
str intro noskip    # запретить пропуск кнопкой
```

Имя из `videos.txt`. По умолчанию ролик пропускается крестиком или Start.

После ролика экран остаётся чёрным: видео затирает кадровые буферы. Ставьте
`bg` и `fade in` сразу следом.

## Ветвление

### `choice` — выбор игрока

```
choice
  "Согласиться"  -> agree
  "Отказаться"   -> refuse
endchoice

@agree
Он кивнул.
goto next

@refuse
Он покачал головой.

@next
```

Каждый вариант — текст в кавычках, стрелка и метка.

### `goto` — переход

```
goto ending_good
```

### `set` и `if` — флаги сюжета

```
set 3 1                  # записать в флаг 3 единицу
if 3 1 goto met_sylvie   # если флаг 3 равен 1, перейти
```

**Флагов 256**, номера от 0 до 255, значения тоже от 0 до 255 — то есть
флаг хранит не только «да/нет», но и число. Флаги попадают в сохранение,
поэтому в них удобно держать пройденные события, выборы и счётчики.

Двести пятьдесят шесть — это потолок формата: номер флага занимает один
байт в опкоде, больше туда не поместится. Компилятор проверяет и скажет
прямо:

```
set: номер флага 300 вне диапазона 0..255
```

### `end` — конец

```
end
```

Останавливает сценарий.

## Экраны

### `splash` — заставка

```
splash 4
Эта история вымышлена.
Совпадения случайны.
endsplash
```

Число — секунды. Текст выводится по центру, поверх чёрного.

### `menu` — титульное меню

```
menu "НАЗВАНИЕ ИГРЫ"
  "НАЧАТЬ"    -> start
  "ЗАГРУЗИТЬ" -> load
endmenu
```

Пункты работают как переходы по меткам, но **`load` — особое слово**: оно
открывает экран загрузки поверх титульного. Если игрок передумает, он
вернётся к меню.

Фон под меню ставится обычной командой `bg` перед ним.

## Галерея

### `gallery` — отметить сцену открытой

```
bg meadow
gallery "Луг" meadow

scene rain 10
gallery "Дождь за окном" rain 10
```

Первый аргумент — подпись в галерее, до 19 символов кириллицей. Второй —
имя картинки **или анимированной сцены**: если такая сцена есть в
`art/scene/`, галерея покажет её анимированной, а не одним кадром.
Третий необязательный аргумент задаёт задержку между кадрами.

Ограничение на кадры здесь то же, что у `scene`, — четыре: галерея
показывает сцену ровно так, как она выглядит в игре.

Признак «открыто» хранится на карте памяти, **отдельно от слотов
сохранения** — галерея копится между прохождениями, и новая игра её не
стирает. Запись происходит только при первом открытии сцены, поэтому
повторные прохождения идут без пауз.

Команду стоит ставить рядом с показом самой сцены: тогда игрок открывает
её ровно тогда, когда увидел.

### Пункт в титульном меню

```
menu "НАЗВАНИЕ"
  "НАЧАТЬ"    -> start
  "ЗАГРУЗИТЬ" -> load
  "ГАЛЕРЕЯ"   -> gallery
endmenu
```

Слово `gallery` здесь особое, как и `load`: оно открывает экран галереи, а
не переходит по метке. Внутри влево-вправо листают открытые сцены,
треугольник закрывает.

## Сохранения

### `chapter` — точка сохранения

```
chapter "Лекция"
fade out 1s
bg lecturehall
fade in 1s
```

Метка главы делает три вещи: принудительно начинает новый файл главы,
заносит название в таблицу и отмечает место в байткоде.

**Глава обязана выстроить сцену с нуля** — поставить фон и спрайты. При
загрузке движок начинает ровно отсюда, и без фона игрок увидит чёрный экран
с текстом. Компилятор это проверяет и откажется собирать:

```
глава 'Плохая': реплика раньше, чем bg или scene.
```

Номер главы — хеш её названия, а не порядковый. Поэтому вставка новой главы
в середину сценария **не ломает старые сохранения**. Ломает только
переименование, и игрок увидит это как «сохранение не подходит».

Сохраняться можно только на реплике, ждущей нажатия. Сам экран сохранений
вызывается кнопкой L1, загрузки — R1.

## Частые ошибки

**`wait 5` вместо `wait 5s`.** Пять кадров вместо пяти секунд — команда
словно не сработала.

**Проявление до смены фона.** `fade in` перед `bg` показывает старую
картинку, и только потом происходит подмена.

**Длинное тире в реплике.** Исчезает без предупреждения, потому что глифа
нет в шрифте.

**Загрузка сразу после `voice`.** Обрывает реплику на полуслове.

**Глава без фона.** Компилятор откажется собирать — и правильно сделает.

**Отрицательный `y` у персонажа.** Срезает голову: спрайты обрезаны до 176
пикселей и при `y = 0` уже помещаются целиком.
